📖 About The Project

World War Bot is a multiplayer strategy & war game developed for the Bale platform.

Players can create and manage their own nations, develop their economy, build armies, form alliances, declare wars, trade resources, and compete for global dominance.

«💡 The entire project is being developed from scratch by Darkknight Studio.»
